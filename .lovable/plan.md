## Goal

Replace the mock neighborhood report card with **live data** for the 10 indicators you picked, keyed off the census tract returned by the Census geocoder.

## The 10 indicators & where the data comes from

All from **two free, no-key federal sources**:

| # | Indicator | Source | Variable |
|---|---|---|---|
| 1 | Total population | ACS 5-yr | B01003_001E |
| 2 | % children below poverty | ACS 5-yr | B17006_002E / B17006_001E |
| 3 | Median household income | ACS 5-yr | B19013_001E |
| 4 | Unemployment rate | ACS 5-yr | B23025_005E / B23025_003E |
| 5 | % age 25+ no HS diploma | ACS 5-yr | sum(B15003_002..016) / B15003_001E |
| 6 | % uninsured (all ages) | ACS 5-yr (S2701) | S2701_C05_001E |
| 7 | % built before 1960 | ACS 5-yr | sum(B25034_009..011) / B25034_001E |
| 8 | % renters paying >50% (severe rent burden) | ACS 5-yr | B25070_010E / B25070_001E |
| 9 | Renter share % | ACS 5-yr | B25003_003E / B25003_001E |
| 10 | USDA Low-Income Low-Access (1mi urban) flag | USDA Food Access Research Atlas | LILATracts_1And10 |

## Architecture

```text
Browser address input
   │
   ▼
Census Geocoder (already wired) → returns state/county/tract FIPS
   │
   ▼
Server function: getTractIndicators({state, county, tract})
   │
   ├──► fetch Census ACS API (1 call, all 10 ACS variables)
   └──► lookup USDA flag (bundled JSON, keyed by 11-digit tract FIPS)
   │
   ▼
Report card UI re-renders with real values
```

## Files to change

**New**
- `src/lib/tract-indicators.functions.ts` — server function that calls `https://api.census.gov/data/2022/acs/acs5?get=...&for=tract:XXXX&in=state:XX+county:XXX` and merges in the USDA flag.
- `src/data/usda-food-access.json` — tract-FIPS → boolean lookup, generated by a script that downloads & filters the USDA Food Access Research Atlas to just the `LILATracts_1And10` column. Stored as a compact object so it's small enough to bundle.
- `scripts/build-usda-lookup.ts` — one-time generator script (run during this task, output committed).

**Edited**

## Display format

Top stat strip (3 cards) keeps current layout:
- Median income · Renter share · Unemployment rate

Report card list (replaces the current 6 letter-grade rows) becomes 7 plain-language rows:
- Total population · Children in poverty · No HS diploma · Uninsured · Old housing (pre-1960) · Severe rent burden · Food access (USDA flag)

Each row shows the **raw value** + a one-line context note (e.g. "23% of renters spend more than half their income on rent — Hartford average is 14%"). Severity pill (good/watch/concern) is computed from simple thresholds I'll define per indicator (e.g. uninsured >15% = concern, 8–15% = watch, <8% = good). I'll keep these tunable in one constants block.

## Caveats / things to flag

- **ACS margin of error**: small tracts can have noisy estimates. I'll show the value but won't surface MOE in v1.
- **USDA flag is a single boolean**, not a percentile — display as "Yes / No" with the definition in a tooltip-style sub-line.
- **USDA data refresh**: the Atlas updates every ~4 years; bundled snapshot is fine for now.
- **Geocoder → ACS handoff**: the geocoder returns 6-digit tract codes; ACS wants the same. I'll normalize once in the server function.
- **Print / Share tabs**: they currently read from the mock `reportCard` array — I'll update them to read the new indicator array so they stay in sync.
